# TODO App / TODO アプリ

## Overview

This is a TODO web application built with React and TypeScript in 90 minutes.
Users can add, view, delete single or multiple tasks, delete all tasks, and have their list persist after page reload.

## 概要

本アプリは React と TypeScript で作成した TODO Web アプリです。
タスクの追加、閲覧、単一削除、複数選択削除、全削除、ページリロード後もデータ保持が可能です。

---

## Features

- Add text to list
- Display list of items
- Delete single item
- Select multiple items
- Delete selected items
- Delete all items
- Persist list after reload

## 機能

- テキスト入力で追加
- リスト表示
- 単一削除
- 複数選択削除
- 選択削除
- 全削除
- リロード後もデータ保持

---

## Tech Stack

- React
- TypeScript
- Vite

---

## Design Decisions

- Kept functionality focused on the required features
- Used localStorage for persistence
- All labels in Japanese for clarity

## 設計方針

- 要件に沿った必要最低限の機能に絞って実装
- データ保存に localStorage を使用
- 全ラベルを日本語に統一
